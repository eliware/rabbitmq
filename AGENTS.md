# AGENTS.md

## Project

`@eliware/rabbitmq` is an ESM RabbitMQ publish/consume helper for Node.js.

## Development

- Run `npm test` for the Jest suite and coverage.
- Run `npm run lint` for Oxlint.
- Run `npm pack --dry-run` to verify package contents.
- Do not commit secrets or local `.env` files.
- Preserve the public ESM API and TypeScript declarations when changing behavior.
